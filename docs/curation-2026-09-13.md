## Validation and compatibility

All eight original manifests passed the current native validator and matched
their index hashes before filtering. The final index is also verified through
the native `RepositoryIndexVerifier` using its existing explicit
`userApprovedUnsigned` mode, including retained manifest cross-checks and the
2.0.39 minimum-version comparison. The CLI's default `verify-repository` is
signed-only and correctly rejects this existing unsigned collection; that is
not worked around by changing app code, trust policy or signing material.

The repository ID (`aroki-testing-modules`), schema and unsigned trust mode stay
unchanged. Only the index timestamp/active list/release notes, README and this
curation record change, plus removal of seven inactive manifest files. Retained
manifest bytes are unchanged. No app code or stable repository is modified.

Existing installed copies are retained by the app and may show `No longer
listed`; this is not a remote uninstall. Users can remove those sources manually.
New imports should offer only Aniworld. Refresh the same collection URL.
